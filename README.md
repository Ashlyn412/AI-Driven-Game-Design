# AI-Driven Game Design Systems Portfolio

## Overview

This project is a single-page portfolio website for an AI-driven game system design concept by Ashlyn_Liang. It presents a design thinking project that connects adaptive difficulty, player data monitoring, procedural content generation, and real-world game AI systems.

The page is intended for academic review, admissions review, portfolio submission, or collaboration discussion. It is designed to communicate both the visual prototype and the research context behind the project.

## Latest Added Requirements

The current version includes several added presentation and navigation requirements:

- The top navigation keeps `Home`, `System`, `Insights`, `Others`, and `Contact me`.
- `Others` is placed immediately to the left of `Contact me`.
- `Others` works as a parent navigation item with a hover and focus dropdown menu.
- The dropdown links directly to the later project sections, including Research Context, Design Rationale, My Contribution, Insights / Dashboard, Literature & Cases, Project Limitations, and Future Work.
- `Contact me` uses the same font size, opacity, color, and interaction style as the other main navigation items.
- The bottom contact area uses the title `Contact` only. The previous wording `Contact section` has been removed.
- The Contact area also includes links to the added project sections so that the later expanded content is visible from the contact area as well.

## Files

- `index.html` - The complete portfolio website. It contains the HTML, CSS, JavaScript, dashboard charts, navigation, project sections, and contact information.
- `README.md` - This documentation file.

## How To Open

Open `index.html` directly in a browser.

No installation, build step, local server, or package manager is required.

## Main Page Sections

The website includes the following sections:

- Home - Project introduction, personal project information, and the core design frame.
- Research Context - Context for adaptive difficulty, player telemetry, procedural content generation, and real-game AI systems.
- Design Rationale - Explanation of how the interface design connects to credible game AI domains.
- System - The main system workflow, including player inputs, model training, core metrics, and generative outputs.
- My Contribution - A clear summary of the independent design, research, dashboard, and front-end implementation work.
- Insights - A dashboard prototype with KPI cards and charts for evaluation signals.
- Literature & Cases - Academic references and industry cases used to position the project.
- Project Limitations - Critical reflection on demonstration data, algorithm depth, PCG implementation, and privacy ethics.
- Future Work - A four-phase roadmap for playtesting, algorithm refinement, PCG prototyping, and portfolio deployment.
- Contact - Personal contact information and quick links to the major project sections.

## Design Style

The website keeps the original dark blue, minimal, refined technology-oriented visual style. It uses:

- A deep Prussian blue background
- Hermes orange accents
- Tiffany blue highlights
- Fraunces for headings
- Inter for body text
- Thin borders, subtle cards, and restrained shadows

The added sections are designed to match the original typography and layout instead of appearing as separate add-ons.

## Technical Notes

The website is mostly self-contained in `index.html`.

It uses Chart.js from a CDN for the dashboard charts. If the page is opened without internet access, the main page content will still display, but the charts may not render.

The page also uses Google Fonts for Fraunces and Inter. If the fonts cannot load, the browser will fall back to standard local fonts.
